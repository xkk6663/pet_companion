## A 版｜完整版（推荐）

### 桌宠伴侣・基于 ESP32-S31 双核的端云一体桌面机器人

**项目描述**：基于 ESP32-S31 双核平台构建桌面陪伴机器人，双核运行 FreeRTOS SMP，实现语音对话、端侧人脸打卡、800×480 LVGL 交互与 16 个云端工具调用；配套浏览器管理端，内部 RAM 静态占用较改造前下降 81.6 KB。

**开发环境**：ESP-IDF v6.1、VS Code + CMake/Ninja、idf.py/esptool、PowerShell 7、Git、Python 串口与验收脚本、pytest（离线切帧仿真）、Docker + systemd（云端网关）。

**技术栈**：C/C++、ESP32-S31（RISC-V 双核 @240 MHz，16 MB Flash + 8 MB PSRAM）、FreeRTOS SMP、OV3660 DVP + esp\_video/V4L2、硬件 JPEG 解码、RGB LCD + LVGL 9.6、Wi-Fi APSTA/lwIP、WebSocket/HTTP、cJSON/MCP、FATFS/littlefs/NVS、SDMMC、ES8389/I2S、A2DP SBC、ESP-DL、静态内存池。

**工作职责**：



1. 针对 17 任务共用内部 RAM、`largest` 仅剩 4 KB 引发 NO\_MEM，重构 FreeRTOS SMP 双核任务与 12 KB 静态池，静态占用降 81.6 KB、`largest` 稳 55 KB。

2. 针对 720p JPEG 单帧 921,600 B 阻塞 DVP，采用三缓冲 + 1 ms staging + 解码下沉 core1，实现 12 fps 采集与 320×180@6.7 fps 取景并存。

3. 针对 NAT 后云端不可达、按换行切帧零接收，改设备外连 WS + JSON 括号状态机 + 1→30 s 退避，7 类用例零丢帧、16 工具 caps。

4. 针对 HTTP 单任务 8 KB 栈被长事务堵死，改 202 + 代际轮询，20 个 API 可预期返回，覆盖媒体、截图与打卡流水。

5. 针对 SD 写延迟与掉电损坏，实现 AVI 流式封装 + `idx1` 回填、face\_db 双世代 + CRC32，录像可播、人脸库不丢。

6. 针对时延与隐私，落地端侧检测 <100 ms、识别 324 ms，模型 1.19 MB 按需加载，人脸不出设备、断网可打卡。

7. 针对单 player 顶掉音乐，拆 TTS (pri=2) / 音乐 (pri=1) 双通道 + 暂停续播，codec 租借 60 s 归还，TTS 后音乐无缝接上。

8. 针对重连写 NVS 触发 flash 擦写、打断 RGB 444 µs 供数，改 RAM 存储 + 跳过 commit，重连 flash 写 0 次、花屏消除。

9. 针对单槽 7.75 MB、应用 7.43 MB 使双槽 OTA 不成立，核算 ≤5.1 MB / 槽、梳理 `otadata` 回滚与停 DMA，给出裁剪 + 双槽方案。

10. 针对 “按了没反应” 难定位，建 `[GW]`/`EVT:`/`[pet_device]` 三段日志 + 7 类切帧用例，实现按段排除并修复 F51 类 bug。

## B 版｜一页 6 条（按 JD 删减）



1. 针对 `largest` 仅 4 KB 与 NO\_MEM，重构 SMP 任务 + 12 KB 静态池，静态占用 −81.6 KB。

5. 针对时延与隐私，端侧检测 <100 ms、识别 324 ms、模型 1.19 MB 按需加载。

6. 针对 flash 擦写打断 RGB 供数，重连写 0 次、花屏消除。
