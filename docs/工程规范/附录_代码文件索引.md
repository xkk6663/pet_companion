# 附录：代码文件索引

> 截至 2026-11-20（分支 `端侧人脸识别`；分层解耦 P0~P4 已实施并完成上机验收）。
> 新增模块后同步更新本表。口径 = `main/` 下全部 `.c` / `.cpp` / `.h`（**173 个文件、70,939 行**，其中 `ui/fonts` 生成字模 20,228 行）。
> 分层规则见 [01_工程分层架构](01_工程分层架构.md)：L0 `platform/` → L1 驱动 → L2 服务 → L3 业务 `ai/` → L4 表达 `ui/`，
> 机器可查的约束是 `python tools/layering/layer_guard.py --baseline tools/layering/layering_baseline.json`。
> ★ 旧版索引（2026-09-13）描述的 `link_manager / udp_voice / record_service / session_manager`
> 属 **main 分支（传声机工程）**，本分支不存在；`color_hsv.c/h` 已于 §73.12 **删除**。
